# cumpleyuri

Web personal para el cumpleaños de Yuri — 22 de mayo de 2026.

Stack: Vite + React + TypeScript + Tailwind + Framer Motion.

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Las fotos (.jpg) y el audio se sirven directo desde raw.githubusercontent.com — no se incluyen en el bundle.
